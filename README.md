<h1 align="center">Twitch Chat Overlay</h1>

<p align="center">
  Чат Twitch поверх всех окон — без фона, с чёткой обводкой текста,<br>
  клики проходят насквозь, игра не теряет фокус.
</p>

---

## Возможности

- **Поверх всех окон** и **не перехватывает управление** — мышь и клавиатура остаются у игры или другой программы.
- **Без фона** — видны только буквы с чёрной обводкой и тенью, читаются на любом фоне.
- **Сообщения исчезают** через настраиваемое время с плавным затуханием (или не исчезают вовсе).
- **Настройки**: канал, время показа, затухание, шрифт, размер, жирность, толщина обводки, тень, цвет текста, количество сообщений, отступы.
- **Положение и размер** окна чата задаются мышью.
- Цвета ников из Twitch; слишком тёмные автоматически осветляются.
- Анонимное подключение — логин и токен не нужны.
- Управление через значок в трее.

## Установка

1. Откройте [**Releases**](../../releases/latest) и скачайте `TwitchChatOverlay-Setup-x.y.z.exe`.
2. Запустите установщик. Права администратора не нужны.
   При желании отметьте «Запускать вместе с Windows».

> Windows SmartScreen может предупредить о неизвестном издателе — нажмите
> «Подробнее» → «Выполнить в любом случае». Программа не подписана сертификатом.

## Использование

1. При первом запуске откроются настройки — введите ник канала и нажмите **«Применить и сохранить»**.
2. Нажмите **«Переместить / изменить размер чата»**, перетащите окно в нужное место,
   потяните за угол справа внизу для изменения размера. **Двойной клик** — готово.
3. Окно настроек можно закрыть — оверлей продолжит работать.
   Настройки, скрытие, очистка чата и выход — **правый клик по значку в трее**.

Настройки хранятся в `%APPDATA%\TwitchChatOverlay\config.json`.

### Ограничения

- В **эксклюзивном полноэкранном** режиме игры Windows не показывает окна поверх.
  Используйте режим «**в окне без рамки**» (borderless / windowed fullscreen).
- Эмодзи Twitch показываются текстом (кодом смайла).

## Запуск из исходников

```bash
pip install -r requirements.txt
python twitch_chat_overlay.py
```

## Сборка установщика

**Локально (Windows):** установите [Inno Setup 6](https://jrsoftware.org/isdl.php) и выполните

```bat
build.bat 1.0.0
```

Установщик появится в папке `Output\`.

**Через GitHub Actions:** создайте тег — установщик соберётся и прикрепится к релизу автоматически.

```bash
git tag v1.0.0
git push origin v1.0.0
```
